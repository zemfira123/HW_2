# HW_2 Система для записи и обработки списков покупок и рецептов
Проект состоит из классов:
- `Ingrigient`-хранит каждый отдельный ингредиент, его количество и единицу измерения;
- `Recipe`-описывает рецепт с перечислением ингредиентов;
- `DietaryRecipe`-является наследником `Recipe`, реализуя описания диетических рецептоы;
- `ShoppingList`-занимается суммированием ингредиентов из различных рецептов.
